# `parse.text.builtin`'s conformance fixtures

Fourteen files across the ten served media types, each one a case the driver has to answer
differently. Every file is generated by `fixtures/gen/gen_text_fixtures.py`, which is also its
provenance record. Regenerate them, and run the twelve suites over them, with:

```console
$ uv run python fixtures/gen/gen_text_fixtures.py
$ uv run python tools/ow_conform.py \
    --card packages/omniweave-office/src/omniweave_office/text/driver.toml \
    --fixtures packages/omniweave-office/fixtures/text
```

## The corpus

| file | what it is for |
|---|---|
| `guide.md` | YAML front matter, setext and ATX headings, ordered, bullet and nested lists, a block quote, fenced code with its language, a pipe table and a thematic break |
| `notes.txt` | paragraphs split on blank lines, each keeping its line breaks |
| `latin1.txt` | bytes that are not UTF-8: read as Latin-1, with an `OW_TEXT_NOT_UTF8` warning |
| `page.html` | headings, an entity, a list, a table with `colspan` and `rowspan`, a block quote, `pre` and `hr`; the `head`, `style` and `script` are not content |
| `page.xhtml` | a self-closing `br`, and an ordered list that starts at 3 |
| `catalog.xml` | the text of each element that has any, in document order |
| `entities.xml` | a DTD declaring nested entities (billion laughs). `defusedxml` refuses it, and `parse()` refuses with `CORRUPT_INPUT` without expanding anything |
| `data.json` | one `path: value` paragraph per leaf |
| `broken.json` | JSON cut short: `CORRUPT_INPUT`, naming the parser's message |
| `events.jsonl` | one paragraph per record |
| `analysis.ipynb` | a markdown cell read as Markdown, a code cell as `python`, its stream output as code |
| `rows.tsv` | one table, its first row the header |
| `logo.svg` | the `title`, `desc` and `text` elements |
| `not_a_document.bin` | an ELF header with no routed media type: `sniff()` returns `()` and `parse()` refuses with `UNSUPPORTED_FORMAT` |

`.gitattributes` keeps every fixture's bytes as written: they are ground truth, pinned by
`EXPECTED.sha256`, and a line-ending conversion would change them.
