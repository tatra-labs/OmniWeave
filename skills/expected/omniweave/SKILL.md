# omniweave — the router

Route a deliverable request to the workflow skill that owns it, then leave.
This skill does not retrieve: `ow_query` and `ow_open` (or `ow query` /
`ow open`) do that.

## When NOT to load this skill

- You already hold the cite: open it with `ow_open`.
- The task is retrieval only ("which document says this"): ask `ow_query`.
- The corpus is unindexed and you do not intend to index it.

### Resolve common ambiguities

- **report vs docx**: a report is authored prose with citations; a docx is a document structure.
- **deck vs pptx**: `omniweave-target-deck` is a toolchain HTML deck; `omniweave-pptx` is an OOXML file.
- **extract vs query**: extract fills named fields across many documents; a single question is `ow_query`.
- **review vs apply-comments**: review checks an artefact against its sources and reports; apply-comments changes it.

## 5. Hand off and leave

workflow reads; nothing later re-opens this skill.
