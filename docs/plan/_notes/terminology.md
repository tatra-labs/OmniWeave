# omniweave — Terminology Lock

**Status:** binding, alongside `charter.md`. One concept, one name.
**Rule for authors:** if a name you want is in §3 (Rejected synonyms), you are wrong and §3 tells you
what to write instead. If a name you want is not here at all, you are introducing a concept — say so
explicitly in your document, add it here in the same change, and expect a reviewer to ask whether it
is really a new concept or an existing one under a new name.

**And the rule is enforced, in both directions, by CI (G27's name checks):**

1. every **declared type name** appearing in `charter.md` or in any plan document has a row in §2.
   A name is declared when it appears in a `python` fence as a `class` statement, a `NewType(...)`
   or `TypeAlias` target, a `Literal[...]` alias name, an annotation, a string forward reference in
   a signature, or a `Protocol` body; or in a SQL fence as a `CREATE TABLE` / `CREATE VIEW` /
   `CREATE INDEX` name. (Widened from "`class` name" by ADR-1 decision 4, which closes `09#Q7`:
   eleven OUT type names reached the charter as annotations and forward references and the old
   wording could not see them.)
2. every §2 term appears in at least one document — a locked name nothing uses is a concept that
   was renamed and left behind;
3. no document contains a whole-token occurrence, inside a code span, of a §3 `token`, unless the
   row's `bannable_by_name` is true, the line carries a negation marker from the closed list
   `{no, not, never, rejected, rejects, forbidden, banned, struck, instead of}` matched as a whole
   token, or `tools/lock_allow.toml` carries an explicit `file:line:token` triple. The allowlist is
   a **ratchet**: `tools/gates.toml` holds its length and `G27(c)` fails on an increase.

The charter itself failed all three before this revision — it shipped `Verdict` and `Layer` in a
module inventory a plan document would have copied verbatim, while §3 lists both as rejected — which
is why the check is mechanical and not a review habit.

**`G27(c)` turns on when four conditions hold, and not before** (ADR-1 decision 6): §2 covers every
name rule 1's parser finds; §3 carries the `token` / `sense` / `bannable_by_name` columns;
`tools/lock_allow.toml` exists; and the residual on a clean tree is zero. Until all four hold,
`G27(c)` is registered in `tools/gates.toml` with `enabled = false` and a `blocked_by = "ADR-1"`
note, so its absence is visible rather than assumed. This revision discharges the second condition
and the §2 half of the first; the two `tools/` conditions are ADR-1 consequence 3.

Sorted case-insensitively, ignoring a leading `.`, `_`, `[`, `<`, `$` or backtick. The **Kind**
column says what sort of name it is, so a reader can tell a Python type from a SQL table from a wire
protocol at a glance: `concept` · `type` · `enum` · `member` · `fn` (function or method) · `proto`
(Protocol or wire protocol) · `table` · `view` · `column` · `index` · `dist` (distribution) · `pkg`
(import package) · `module` · `file` · `dir` · `cfg` (config key) · `cli` · `invariant` · `const` ·
`code` (error/diagnostic code family) · `entry-point` · `signal` (a registered signal key) ·
`driver-id`. **`gate` is not a Kind:** `tools/gates.toml` is the G-series' register and `G27` clause
d2 resolves a `G<n>` from it ([11](../11-repo-layout.md):2244), so a lock row would be a second home
(ADR-1 decision 3).

## 1. Naming conventions

**Casing.**

| where | convention | example |
|---|---|---|
| distribution | `kebab-case`, always `omniweave-` prefixed | `omniweave-target-pptx` |
| import package | `snake_case`, one per distribution, **no namespace packages** | `omniweave_target_pptx` |
| module | `snake_case`, singular unless it is a registry of many things | `verdict.py`, `codes.toml` |
| Python type, Protocol, enum class | `PascalCase` | `DriverCard`, `ChannelStatus` |
| enum member | `SCREAMING_SNAKE`; the **wire value is the lower-case member name**, for an `IntEnum` as much as a `StrEnum`, so `Rung` is `"decode"` on the wire and in a generated schema. The rule governs JSON, generated schemas, DB columns and every byte-diff-gated generated artefact; it does **not** govern an **author-facing config artefact** — `.omniweave/policy.d/*.toml`, `omniweave.toml`, `pricebook.toml`, `retrieval.toml` — where the member name is what the author reads against [05](../05-ingest-and-routing.md) §4.2's ladder (ADR-4 D3) | `Trust.EXTRACTED` → `"extracted"`; `Rung.DECODE` → `"decode"` |
| function, method, variable | `snake_case` | `build_verdict()`, `content_digest` |
| constant, limit | `SCREAMING_SNAKE`; a ceiling is `MAX_*`, a floor is `MIN_*` | `MAX_GRID_SLOTS`, `MIN_CHARS` |
| SQL table | `snake_case`, **singular** | `block`, `segment`, `route_decision` |
| SQL view | `snake_case`, prefixed `ow_` when it is a head/live projection | `ow_block_head`, `ref_unresolved` |
| SQL index | `<table>_<purpose>` | `block_cite`, `edge_bound`, `cache_gc` |
| SQL column holding a digest | `*_sha256` is **always** a 32-byte sha256. `*_digest` is a digest of unspecified width whose **column type** says which: BLOB ⇒ a 16-byte `ow128`, TEXT ⇒ `sha256_canonical` hex. **Where one name would otherwise carry both types, the sha256 one is spelled `_sha256`.** **Never `hash`.** | `content_digest` (BLOB, `ow128`) vs `content_sha256` (TEXT); `policy_digest` (TEXT); `card_sha256` |
| config key | `snake_case` under a `[section]`; a duration ends `_ms` or `_s`, a size ends `_bytes` or `_mb`, a count is a bare plural | `lease_ms`, `min_free_bytes`, `max_workers` |
| env var | `OMNIWEAVE_` + `SCREAMING_SNAKE`, one per config key | `OMNIWEAVE_MCP_LISTED` |
| CLI | `ow <group> <verb>`, both lower-case, **no aliases**; a group is created only at three or more verbs, and **no two groups may differ only by a trailing `s`** (G25) | `ow store verify`, `ow drivers check` |
| CLI flag | `--kebab-case`; a named override starts `--allow-` or `--accept-` | `--allow-cost`, `--accept-partial` |
| error code | `OW-<AREA>-nnn` (the human form) with a `OW_SCREAMING_SNAKE` symbol (the stored and wire form) | `OW-S-010` / `OW_SNAPSHOT_EXPIRED` |
| wire protocol | `<name>/<MAJOR>`, lower-case | `omniweave-target/1`, `parse/1`, `owsvg/1` |
| driver id | `<port>.<subject>.<impl>`, all lower-case `[a-z0-9_]` | `parse.office.anydoc` |
| prompt-safe token | a one-letter sigil + digits, optionally corpus-qualified | `handbook:d7#412`, `e412` |

**Prefixes and suffixes that mean something.**

- **`ow`** — the reserved vendor. `ow128`, `ow_*` views, `x.ow.*` extension keys, `<ow:untrusted>`,
  `ow:<section>` answer markers, the `ow` console script. **No third party may use it.**
- **`om`/`omni`** — never abbreviated. It is `omniweave` or `ow`, nothing in between.
- **`_sha256`** — always a 32-byte sha256. **`_digest`** — a digest whose width the **column type** gives: BLOB is `ow128`, TEXT is `sha256_canonical` hex. Where one name would carry both types it is split, and the sha256 half takes the `_sha256` spelling (`content_digest` / `content_sha256`; `community.member_digest` / `cohort.member_sha256`). The rule that matters is **one name, one type**; renaming `policy_digest`, `config_digest`, `il_digest` and six other locked sha256-based names to save a slogan would have been the wrong trade.
- **`_id`** — a durable surrogate integer, store-local, never in a prompt. **`cite`** — a prompt-safe
  token. **`addr`** — a type-free path address. Three jobs, three suffixes, never interchanged.
- **`origin_*`** — ownership provenance (`origin_operator`, `origin_driver`), never trust.
- **bare `gen`** — the per-document **parse** generation, and nothing else. Every other generation
  counter carries a qualifying prefix (`artifact_gen`, `card_gen`, `staged_gen`, `at_gen`,
  `retired_gen`, `built_gen`, `last_seen_gen`), and the monotonic **run** counter is `generation`.
- **`MAX_*`** — a ceiling a tenant may clamp *below* and never widen, and which the producer is
  built never to exceed. A number its own producer overshoots by design is a **`*_TARGET_*`**, not a
  `MAX_*`: `SEGMENT_TARGET_TOKENS = 1200` is the target, `MAX_SEGMENT_TOKENS = 2048` is the ceiling.
  **`MIN_*`** — a floor, and there is exactly one that gates startup: `MIN_SQLITE`.
- **`*_v` / `*_version`** — `driver_schema_v` and `op_version` are integers **at every site**, the
  `producer` column and the `Producer` field included; `RELEASE`, `driver_version` and
  `model_version` are strings.
- **`ts_a` / `ts_b`** — a `TextSpan` (chars inside one block's text). **`os_*`** — an `OriginSpan`
  (the address in the original container). **Never mixed.**
- **`_frac`** — a `[0,1]` float. **`_rate`** — a `[0,1]` float measured over a population.
  **`_micros`** — money, in millionths of the pricebook currency. **`_ms` / `_ns`** — durations.

**A type and its table or column, and when a shared name is a collision.** A type and the table or
column it is stored in take **two §2 rows when they denote one concept**, and are a **collision**
when they denote two. §2 carries six such case pairs — `Block`/`block`, `Diag`/`diag`, `Doc`/`doc`,
`Part`/`part`, `Run`/`run`, `Segment`/`segment` — each one concept in two Kinds, and `Cite`/`cite`
and `Addr`/`addr` are NewTypes over their own column and take two rows for the same reason.
`Unit`/`unit` denoted **two** concepts, which is why the output unit is now `OutUnit` (§3).

**Plurals and verb forms.**

- SQL tables are **singular** (`block`, not `blocks`) because a row is one of the thing. The one
  exception is a table whose row *is* a set (`entity_band` holds bands).
- A collection-valued config key is a bare plural (`enabled`, `formats`, `lanes`).
- A CLI verb is an **imperative** (`verify`, `explain`, `bless`), never a gerund or a noun.
- A function that returns a decision is named for the decision (`resolve`, `evaluate`, `admit`,
  `plan`), not `get_*` or `compute_*`.
- A function with a side effect on the store is named for the effect (`rebind`, `converge`, `freeze`).
- **`check` vs `verify` vs `doctor`:** `check` is a CI-shaped byte-diff or contract assertion that
  exits non-zero; `verify` re-derives from stored bytes and compares; `doctor` reports the environment
  and never fails on a *warning*.
- **`emit` vs `render` vs `serialize`:** `emit` writes a generated artefact to disk (`ow schema
  emit`); `render` turns internal state into text for a human or a model (`Answer.render`);
  `serialize` turns Blocks into a named view **and its `SpanMap`** (`serialize() -> (str, SpanMap)`).

## 2. The lock

**745 rows.** 407 from the revision before ADR-1, 313 merged verbatim from the nineteen documents'
"New terms" sections, 24 authored here because no document offered them (`02#1`, `04#Q3`,
`13#Q-Q4`, and the three `index` rows §1's `<table>_<purpose>` convention already names), and
`nfc()` — defined by [ADR-5](../adr/0005-byte-exactness-chain.md) decision 1, claimed by that ADR's
consequence table "through ADR-1's bulk pass", and missed by the pass itself. Its arrival is what
makes [`../glossary.md`](../glossary.md)'s index **745 against 745** rather than one ahead.

**This section is the sole home of a definition.** [`../glossary.md`](../glossary.md)'s index carries
the same names, and its `Definition` and `Kind` columns are **generated** from here by
`tools/gen_glossary.py` and byte-diff gated; its `Specified in` column, its "Do not confuse" and its
"Collisions resolved" sections are its own facts and stay hand-written. One fact, one home
(ADR-1 decision 2).

`Specified in` names the **owning document** — the one plan document carrying the term's definitional
occurrence — and the section inside it. `**none**` means no plan document specifies the name; every
such row is a finding against rule 2, not a licence. `Rejected` carries the spellings §3 refuses for
this term, so a reader who arrives at the wrong name from either direction lands on the right one.

## 3. Rejected synonyms

**106 rows, one backticked `token` each, and the rejection is always *in a sense*.** A token is wrong
**in the sense the row names** and right elsewhere: `parse` is a locked Port and a rejected cache
layer; `Evidence` is the routing record and is rejected for two other things. The old sixty rows
packed several tokens and their senses into one prose cell, which is why check 3 could not be written
against them at all ([12](../12-performance.md):1901-1914, `12#D1`). Write the `Use instead` column.

`bannable_by_name` is **true** where the row names a thing the framework *bans*, so a document
stating the prohibition must be able to name it — `--force`, `pass_with_warnings`, `MessagePack`,
`pydantic`, a loopback TCP `port`. Check 3 exempts those rows everywhere; every other row it flags on
a whole-token occurrence inside a code span, unless the line carries a negation marker or
`tools/lock_allow.toml` carries a `file:line:token` triple for it (see the CI rules above).

|---|---|---|---|---|
| `Node` | for the L2 node type | false | **Block** | One node type, one name. |
| `Element` | for the L2 node type | false | **Block** | One node type, one name. |
| `Item` | for the L2 node type | false | **Block** | One node type, one name. |

## 4. Reserved and forbidden

**Reserved to omniweave, and a third party may not use them:**
the `ow` extension vendor (`x.ow.*`), the `ow` console script, the `omniweave-*` distribution prefix,
the `OMNIWEAVE_` env prefix, the `omniweave.drivers` / `omniweave.targets` / `omniweave.backends` /
`omniweave.operators` entry-point groups, the `OW-*` and `OW_*` code namespaces, the `ow:` answer
section markers, the `<ow:untrusted>` element, `data-ow-el` / `data-ow-cite`, the four cite sigils
`d` `e` `c` `k`, and the five Port names.

**Forbidden anywhere in the framework:**

- a field named `html`, `markdown` or `md` on any model class (a build-failing test asserts it);
- a second representation of a block's text, structure or geometry;
- `sqlite3.connect`, `conn.commit()` or `BEGIN` outside `omniweave_core/store/`;
- `subprocess` outside `omniweave_core.toolchain` and `omniweave_core.host.subproc`;
- `zipfile.ZipFile(..., 'w'/'a'/'x')` or `shutil.make_archive` outside `omniweave_core.out.opc`;
- `opentelemetry` outside `omniweave_serve.otlp`;
- `EntryPoint.load()` under `omniweave_core/drivers/`;
- `importlib.import_module` / `__import__` outside `host/`;
- `os.getcwd()`, `Path(".")`, `time.time()`, `random`, `secrets`, `uuid4`, `datetime.now` in library
  code, and all of them in `route/eval.py`, `retrieve/plan.py` and every `omniweave-target-*`;
- `sys.exit` in library code;
- a bare `except` around a digest, a cache key, a code fingerprint, a probe, a baseline read or a
  retrieval channel;
- `revision="main"` or an absent weights revision;
- a loopback TCP listener for any framework-internal channel — driver hosting (S4) and the Toolchain
  seam (S2) use 0600 unix sockets, owner-only named pipes or stdio, and a long-lived local IPC
  daemon for parse/embed/index/schedule is banned outright. **Two loopback TCP endpoints are
  sanctioned and named** and no third may be added without amending the charter: an attached or
  spawned model server (S3, token-authenticated) and `ow serve --http` (which refuses a
  non-loopback bind without `--api-key`);
- a currency field on a driver-facing type or a DriverCard;
- a `--force`, a `--warn-only`, a `--fix`, or a gate bypass.
