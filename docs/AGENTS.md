# AGENTS.md — omniweave

**GENERATED** by `ow surface emit` from `omniweave.surface.registry`, and byte-diff gated by
G25. Do not edit this file: `ow surface emit --check` fails on a hand edit and the next
`ow surface emit` overwrites it. Change `packages/omniweave/src/omniweave/surface/registry.py`
and re-emit.

**omniweave** — Indexes PDF/DOCX/PPTX/XLSX/HTML/EPUB/scans into a SQLite corpus with page and
polygon provenance, serves cited passages to an agent, and compiles agent output back into
editable PPTX/DOCX/decks. Local-first. No egress by default.

## Exit codes

Every non-zero exit prints the code, the message and the fix command — never a traceback. The
exit code is a pure function of the exception class, which is why the rows below that name no
class name what they are instead: a verdict, a gate status or a detection result is not raised.

| code | meaning | derived from |
| --- | --- | --- |
| 0 | ok — also `low_confidence`, and also `absent` unless `--fail-on` names it | — |
| 1 | usage or configuration error | `UsageError`, `ConfigError`, `ResourceLimit` |
| 2 | not found: no such corpus, cite, addr, document or Action | `NotFoundError` |
| 3 | `verdict = absent` (only with `--fail-on absent`) | a `Verdict`, not an exception |
| 4 | `verdict = degraded` (only with `--fail-on degraded`) | a `Verdict`, not an exception |
| 5 | budget exhausted / `DEFERRED_BUDGET` — the message names the approving command | `BudgetExhausted` |
| 6 | policy refusal: licence tier, `restriction_bits`, a missing egress grant, a path outside roots | `PolicyRefusal` |
| 7 | store busy: another writer holds the corpus (names host, pid, age) | `StoreBusy` |
| 8 | an OUT gate did not return `passed` — `ow out check`, `ow out verify --class render` | a `GateStatus`, not an exception |
| 9 | not configured (`ow install --check`) | a detection result, not an exception |
| 64 | required capability missing — matches `omniweave-target/1`'s exit 64 | `CapabilityMissing` |
| 70 | internal error (prints the `OW-*` code and the report command) | `InternalError`, and `OwError`'s floor |

## The CLI grammar

- `ow <group> <verb>`, and a group exists only at 3 or more verbs.
- No two groups differ only by a trailing `s`. G25 asserts it, because one of the two would
  silently win.
- There are no aliases. A capability has one name, and a rejected spelling is registered as
  rejected rather than left out.
